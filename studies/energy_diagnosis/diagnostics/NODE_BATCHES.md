# Node-owned batches and delayed backup

`node_batches` runs serial bounded wrappers on the allocated node. The receiver never launches work. Between wrappers it creates verified immutable incremental bundles, retaining all original files and failures. An offline receiver does not prevent the next batch. Node storage is not an independent backup: download before allocation expiry, or add a separately validated persistent-storage destination.

Supply the same validated batch specification used by `batch_coordinator`, with explicit absolute node paths and cutoff. Run from a separate orchestration checkout; do not modify a frozen measurement checkout. `--output` must be a new dedicated control directory outside the measured result root. The scheduler holds an exclusive owner lock. Wrapper execution, checkpointing and transfer share `io.lock`, so transfer cannot overlap measured work. Existing wrapper timeouts, GPU locks, process guards and SSH isolation remain required. The scheduler is a sleeping ancestor of the wrapper during measurement, not a second workload.

A terminal successful existing batch can be adopted without rerunning it; a nonterminal status or ambiguous prior launch stops for review. Failed terminal output is checkpointed before stopping. Low disk and insufficient remaining time stop further dispatch. Restart revalidates published snapshot chains; changed specifications are rejected. Never run the old client dispatcher concurrently: hand off after its final remote wrapper terminates, preserve its receipts, then retire it.

`receive_node_batches` needs the SSH fields in the existing specification, plus `node_output` and `remote_repository` pointing to the orchestration checkout. It periodically requests missing immutable bundles, verifies hashes and builds receipts compatible with `archive_results --restore-receipt`. Interrupted transports are retried; verified prior bundles are retained. Transfers occur during a bounded between-batch opportunity. A disconnected Mac can resume the receiver later using the same output directory. A sleeping Mac does not run the receiver; use a login launcher if automatic restart after reboot is needed.

The transfer command uses a 180-second node-side timeout. It releases its lock on disconnect or timeout. The default interbatch opportunity is 45 seconds. The reserved storage floor is 8 GiB. Never silently prune evidence to make room. Stop on invalid data; do not treat energy checks as correctness checks or require favorable outcomes.
